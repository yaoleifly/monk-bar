## ⚡️ MonkBar v1.7.0

### 中文

对齐 2026-11-17 的 monk.party。

- 付费 Key 现在可调用五个模型：`monk`、`monk-fast`、`monk-coding`、`monk-free`，以及新的 `monk-opus`（Claude Opus 5.5，走 Opus 钱包按量扣费，需在用户中心充值）。菜单模型行显示全部五个。
- 公平限额改为 1:1 计数：每个请求计 1 次，不再按输入量加权。默认上限为当日内部计量 200，1 小时 480 次或 20M 输入 Token，6 小时 1600 次或 55M。响应里的数字仍然优先。
- 「加权请求」文案改为「请求次数」，与现在的计数方式一致。

下载 `MonkUsage-v1.7.0-macOS-Tahoe-Universal.zip`，解压后把 `MonkUsage.app` 拖入 `/Applications`。通用二进制（arm64 + x86_64），macOS 13 及以上。macOS 27 只用其中的 arm64。包内是 ad-hoc 签名，没有 Developer ID，也没有公证。

### English

Tracks monk.party as of 2026-11-17.

- Paid keys can now call five models: `monk`, `monk-fast`, `monk-coding`, `monk-free`, and the new `monk-opus` (Claude Opus 5.5, metered from the Opus wallet — top up in the user center). The menu lists all five.
- Fairness counting is now 1:1: every request counts once, no prompt-size weighting. Fallback caps are daily internal meter 200, 480 calls or 20M prompt tokens per hour, 1600 calls or 55M per 6 hours. Server-returned values still win.
- The "weighted requests" label now reads "requests" to match the counting.

Unzip `MonkUsage-v1.7.0-macOS-Tahoe-Universal.zip` and move `MonkUsage.app` to `/Applications`. Universal 2 for macOS 13 and later; macOS 27 runs the arm64 slice. The bundle is ad-hoc signed only. There is no Developer ID signature and no notarization.
