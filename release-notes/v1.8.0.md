## ⚡️ MonkBar v1.8.0

### 中文

对齐 2026-11-18 的 monk.party 与 MONK 宇宙设计语言。

- 新增「💎 Opus 钱包」菜单区：实时余额（低余额/空余额显示 ⚠️）、今日已扣、日限额进度条、一键去充值；未开通钱包时显示开通入口。需要完整 `sk-monk-*` Key（设置页「本机 Key」或 `MONK_API_KEY` 环境变量），掩码 Key 会提示贴完整 Key。
- 模型行按计费方式分区：`订阅 monk · monk-fast · monk-coding · monk-free` 与 `按量 monk-opus（Opus 钱包）`。
- 首次运行未配置邮箱时，菜单显示「三步开始」引导（下单 → 填邮箱 → 看用量），不再是空白菜单。
- 新增「MONK 宇宙 ↗」菜单项，一键打开 universe.monk.party。

下载 `MonkUsage-v1.8.0-macOS-Tahoe-Universal.zip`，解压后把 `MonkUsage.app` 拖入 `/Applications`。通用二进制（arm64 + x86_64），macOS 13 及以上。macOS 27 只用其中的 arm64。包内是 ad-hoc 签名，没有 Developer ID，也没有公证。

### English

Tracks monk.party and the MONK-universe design language as of 2026-11-18.

- New "💎 Opus Wallet" menu block: live balance (⚠️ when low/empty), today's spend, daily-limit bar, and a top-up link; when the account has no wallet it shows an activation entry. Requires a full `sk-monk-*` key (the "本机 Key" field in Settings or `MONK_API_KEY`); masked keys are prompted to paste the full one.
- Model line split by billing: `订阅 monk · monk-fast · monk-coding · monk-free` vs `按量 monk-opus（Opus 钱包）`.
- First-run experience: with no email configured the menu shows a "三步开始" guide (order → set email → view usage) instead of a bare error.
- New "MONK 宇宙 ↗" menu item opening universe.monk.party.

Unzip `MonkUsage-v1.8.0-macOS-Tahoe-Universal.zip` and move `MonkUsage.app` to `/Applications`. Universal 2 for macOS 13 and later; macOS 27 runs the arm64 slice. The bundle is ad-hoc signed only. There is no Developer ID signature and no notarization.
