## ⚡️ MonkBar v1.6.0

### 中文

对齐 2026-10-14 的 monk.party。

- 用量查询仍是 `POST https://monk.party/monk-api/lookup-order`（下单邮箱，可选订单号）。查无订单时提示中文，不再直接显示 `No matching order.`
- 账户页只返回 Key 末四位。菜单和看板显示掩码。完整 `sk-monk-*` 在购买邮件里，可填到「本机 Key」或环境变量 `MONK_API_KEY`，只用于探测 `monk-fast`，不会放进用量查询。
- 付费 Key 可调用 `monk`、`monk-fast`、`monk-coding`、`monk-free`。Base URL 仍是 `https://monk.party/v1`。
- 接口没带上限时，按公开值显示：当日内部计量 200，1 小时 800 次或 60M 输入 Token，6 小时 2400 次或 90M。响应里的数字优先。Token 记为近 14 天。
- 续费打开账户页，在同一把 Key 上顺延。月卡支付宝 ¥30 / 30 天，或 Stripe $5 / 30 天；邮箱域名含 edu 九折。
- macOS 26 显示为 Tahoe，macOS 27 显示为 Golden Gate。

下载 `MonkUsage-v1.6.0-macOS-Tahoe-Universal.zip`，解压后把 `MonkUsage.app` 拖入 `/Applications`。通用二进制（arm64 + x86_64），macOS 13 及以上。macOS 27 只用其中的 arm64。包内是 ad-hoc 签名，没有 Developer ID，也没有公证。

### English

Tracks monk.party as of 2026-10-14.

- Usage lookup is still `POST https://monk.party/monk-api/lookup-order` with the order email and an optional trade number. A missing order is reported in Chinese.
- The account page returns a masked key. The menu shows that mask. Put the full `sk-monk-*` from the purchase email in 本机 Key, or set `MONK_API_KEY`, to ping `monk-fast`. That value is not sent with lookup.
- Paid keys can call `monk`, `monk-fast`, `monk-coding`, and `monk-free`. Base URL remains `https://monk.party/v1`.
- If the payload omits a cap, the app falls back to the published limits: daily internal meter 200, 1 hour 800 calls or 60M prompt tokens, 6 hours 2400 calls or 90M. Server fields win. Tokens are the last 14 days.
- Renewal opens the account page and extends the same key. Alipay ¥30 / 30 days, or Stripe $5 / 30 days. Ten percent off when the email domain contains edu.
- macOS 26 is labeled Tahoe. macOS 27 is labeled Golden Gate.

Unzip `MonkUsage-v1.6.0-macOS-Tahoe-Universal.zip` and move `MonkUsage.app` to `/Applications`. Universal 2 for macOS 13 and later; macOS 27 runs the arm64 slice. The bundle is ad-hoc signed only. There is no Developer ID signature and no notarization.
